# أيقونة التطبيق

`icon.png` و`icon_foreground.png` مصدر أيقونة "سمَّعلي" — شعار المصحف
المفتوح (نفس مسار `AppIcons.book` المستخدَم داخل التطبيق) على خلفية
أخضر العلامة `#1B5E4A`. مُولَّدان برمجياً (Pillow) لا برسم يدوي، عشان
يطابقا شعار التطبيق نفسه بالضبط.

- `icon.png` — 1024×1024، الأيقونة الكاملة (خلفية + شعار)، تُستخدم لـiOS
  ولأندرويد القديم (legacy launcher icon).
- `icon_foreground.png` — 1024×1024 بخلفية شفافة، الشعار فقط داخل
  "المنطقة الآمنة" لأيقونات أندرويد المتكيّفة (Adaptive Icons) عشان ما
  يتقصّش عند القناع الدائري/المربع حسب جهاز المستخدم.

بعد أي تعديل على المصدرين، أعد التوليد لكل المنصّات:

```bash
dart run flutter_launcher_icons
```

الإعداد (الألوان، المسارات) في `pubspec.yaml` تحت مفتاح
`flutter_launcher_icons`.
